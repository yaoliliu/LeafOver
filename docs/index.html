GET STARTED

Your paper, your machine.

Clone the repository and run one script. LeafOver installs the TeX packages needed by the JiT example when necessary, then starts the full local workspace.

Python 3.10+ required. Automatic TeX setup supports Debian/Ubuntu and macOS; the app itself also works with an existing TeX installation.

TERMINAL
git clone git@github.com:yaoliliu/LeafOver.git
cd LeafOver
./install.sh
